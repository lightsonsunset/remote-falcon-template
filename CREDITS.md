# Credits and source

Adapted from **Dynamic Menu by Matt Orelup**, with further design and feature development by **Lights on Sunset / christmasdave**.

The original Dynamic Menu template was the starting point for the Lights on Sunset viewer page. This sharing edition retains that lineage while adding substantial changes to navigation, mobile layouts, festive styling, request feedback, song filters, NEW sashes, availability explanations, listening links and the optional Home notice.

## Sharing edition

Template customiser edition 1.4, modified 16 October 2026. The generic template and setup guide were prepared from the customised Lights on Sunset page. Personal show assets and links were removed. The visual builder adds validated settings, an isolated illustrative preview, local backups and generated HTML. FM, donations, PulseMesh and category/NEW filter buttons are optional. The manual package and builder share one canonical source and renderer.

## Other components

The optional seasonal illustrations in `assets/` were generated for this project using OpenAI's built-in image-generation tool, then resized and encoded as WebP with transparency preserved. They are shared with this project under the same GPL-3.0 terms. Artwork dimensions and provenance are recorded in `assets/README.md`. These are generic seasonal illustrations, not third-party show logos. Imported RF artwork belongs to its respective owners and is not bundled or redistributed by this project.

Font Awesome icons are loaded from cdnjs and remain subject to [Font Awesome's licences](https://fontawesome.com/license/free). Remote Falcon provides the live song, queue, vote and availability behaviour. PulseMesh's official download page provides device routing when its optional links are enabled.

This is a community adaptation. The changes are not presented as the work of, or endorsed by, the original template author or Remote Falcon.
