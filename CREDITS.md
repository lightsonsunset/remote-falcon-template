# Credits and source

Adapted from **Dynamic Menu by Matt Orelup**, with further design and feature development by **Lights on Sunset / christmasdave**.

The original Dynamic Menu template was the starting point for the Lights on Sunset viewer page. This sharing edition retains that lineage while adding substantial changes to navigation, mobile layouts, festive styling, request feedback, song filters, NEW sashes, availability explanations, listening links and the optional Home notice.

## Sharing edition

The customiser now offers the original Lights on Sunset layout and Compact console, with shared editing services. The generic template and setup guide were prepared from the customised Lights on Sunset page. Personal show assets and links were removed. The visual builder adds validated settings, an isolated illustrative preview, local backups and generated HTML. FM, donations, PulseMesh and category/NEW filter buttons are optional. Each template’s manual package and customiser export share its canonical renderer.

The sharing template is distributed under GNU GPL version 3. A verbatim copy of the upstream licence is included in [LICENSE](LICENSE). Each ZIP supplies complete editable HTML/CSS starters for Christmas, Halloween, Thanksgiving, Australia Day, US Patriotic and Valentine’s Day. The original Christmas/Halloween filenames are retained; the new files are labelled with their theme and, for Compact console, the template name. Please keep the attribution, modification notice and licence with redistributed copies. The software is provided without warranty; the licence sets out the full terms.

## Other components

The optional Christmas/Halloween WebP illustrations in `assets/` were generated for this project using OpenAI's built-in image-generation tool, then resized and encoded as WebP with transparency preserved. They are shared with this project under the same GPL-3.0 terms. Artwork dimensions and provenance are recorded in `assets/README.md`. These are generic seasonal illustrations, not third-party show logos. Imported RF artwork belongs to its respective owners and is not bundled or redistributed by this project.

Thanksgiving, Australia Day, US Patriotic and Valentine’s Day use transparent illustrations generated for this project with OpenAI’s built-in image-generation tool and optimised as WebP, alongside original lightweight SVG accents. These assets are distributed with the project under GPL-3.0. The small Vegemite jar is a decorative reference; its name remains a trademark of its owner and implies no endorsement.

Font Awesome icons are loaded from cdnjs and remain subject to [Font Awesome's licences](https://fontawesome.com/license/free). Remote Falcon provides the live song, queue, vote and availability behaviour. PulseMesh's official download page provides device routing when its optional links are enabled.

This is a community adaptation. The changes are not presented as the work of, or endorsed by, the original template author or Remote Falcon.

## Optional show-name fonts

Nunito (Rounded), Playfair Display (Elegant), Berkshire Swash (Festive) and Creepster (Spooky) are bundled unmodified from [Google Fonts](https://github.com/google/fonts/tree/47d54ca1ebb14fd864695f1d39dc734f39017c33/ofl). They are distributed under the SIL Open Font License 1.1, separately from the template GPL licence. Each font’s copyright and licence notice is included beside it in `assets/fonts/`. Lights on Sunset loads the selected optional heading font; its Default retains the system font for Christmas/Halloween, uses Playfair Display for Thanksgiving/Valentine’s Day and Nunito for Australia Day/US Patriotic. Compact console uses Nunito for body text and Playfair Display, Creepster or Nunito for seasonal headings, with optional heading overrides.
