# Seasonal artwork

The Lights on Sunset package includes these transparent WebP illustrations for Christmas and Halloween:

- Christmas logos: Santa & friends, Pixel trees & light arches, Starlight garland.
- Halloween logos: Halloween friends, Haunted light show, Moonlight & pumpkins.
- Christmas navbar: Santa hat, Holly & berries, Christmas bells, Christmas tree.
- Halloween navbar: Hanging spider, Glowing pumpkin, Friendly bat.

Logos are 840 × 280 px; navbar artwork is 160 × 160 px. Artwork fits without cropping. The logo name remains editable HTML text and is not part of the image.

These generic illustrations were generated for this project using OpenAI image generation and converted to WebP with transparency preserved. They are distributed with this project under GPL-3.0. They contain no third-party show logos. Imported catalogue artwork is not bundled.

Both template packages include the show-name fonts and their original licences under `fonts/`. Compact console uses CSS decorations for Christmas/Halloween instead of the WebP illustrations.

## Thanksgiving and Australia Day

The `seasonal/` folder includes two transparent illustrated header frames, generated for this project with OpenAI’s built-in image-generation tool and compressed to WebP:

- `thanksgiving-header.webp`: 900 × 600 px, approximately 131 KB. Amber lights and autumn foliage above, with a friendly live turkey, pumpkin pie, cranberries and a small pumpkin below.
- `australia-day-header.webp`: 840 × 560 px, approximately 92 KB. Australian flag bunting and warm lights above, with a BBQ, cricket bat/ball, thongs, beach accents and a small Vegemite jar below.

The frames keep their corner proportions and a clear area for editable HTML text or a show logo. Only the selected theme’s header is loaded. Each new theme also has three optional 840 × 280 px WebP logo illustrations for Lights on Sunset, between 53 and 113 KB each. Australia Day’s three choices are Aussie summer, Flag bunting and Southern stars crest, without floral framing. Transparency is preserved; the show name is not baked into these images.

The original `autumn-leaf.svg`, `turkey.svg` and `southern-cross.svg` are small vector accents for Thanksgiving motion and the seasonal Home icons. Falling leaves cover the viewport, ignore pointer events and disappear for reduced motion. `australian-flag.svg` is retained as a bundled asset; Australia Day now uses header bunting instead of falling flags. They contain no scripts or external dependencies. All new seasonal assets are distributed with this project under GPL-3.0. The Vegemite name remains its owner’s trademark; the decorative reference implies no endorsement.

## US Patriotic and Valentine’s Day

Original transparent illustrations were generated for this project with OpenAI’s image tool and compressed to WebP. Each theme has one 760 × 760 header frame (under 140 KB) and three optional logo illustrations (under 91 KB each). The header frame supplies separately switchable upper and lower artwork. No text is baked into the artwork.

The American flag SVG has 13 stripes and 50 stars. Original eagle and Cupid SVGs supply Lights on Sunset’s seasonal Home symbols; Music, Info and Support use the standard icon library. Hearts use a lightweight SVG. Original firework launches, bursts and fading trails use small HTML elements with CSS animation, without a bitmap or video download. Reduced motion hides fireworks and drifting hearts; decorative elements never intercept taps. No external GIFs or JavaScript are required. These assets are supplied under the project’s GPL-3.0 licence.
