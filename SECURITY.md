# Security

Please report suspected vulnerabilities privately through [GitHub private vulnerability reporting](https://github.com/lightsonsunset/remote-falcon-template/security/advisories/new).

Do not put passwords, RF access tokens, private settings or imported catalogues in public issues. A minimal example using invented show details is usually enough to reproduce a problem.

The customiser runs in your browser. It has no RF account connection or application backend. Settings and imported catalogues are stored locally; imported catalogues are not included in settings backups or generated viewer HTML. Remote images and third-party stylesheet resources are loaded from their configured hosts.

Security fixes target the latest public release. Update the customiser and regenerate your viewer where a release note calls for it.
